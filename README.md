# Служебные сервисы — Планета здоровой кожи

Набор внутренних инструментов клиники. Статический сайт: всё считается в браузере,
сервер не нужен. Развёрнут на GitHub Pages, ветка `main`, папка `/ (root)`.

## Разделы

| Раздел | Адрес | Что делает |
| --- | --- | --- |
| Главная | `/` | список сервисов |
| [Подарочные сертификаты](sertifikaty/) | `/sertifikaty/` | номер и сумма → PDF для печати, поштучно или пачкой |
| [Свободные окна](svobodnye-okna/) | `/svobodnye-okna/` | врач, дата и время → сторис 1080×1920 |

## Структура

```
index.html             главная со списком сервисов
assets/prata.woff2     шрифт Prata (SIL OFL), общий для всех страниц
sertifikaty/index.html генератор сертификатов (pdf-lib и шрифты встроены в файл)
svobodnye-okna/        генератор сторис, фоны врачей в svobodnye-okna/assets/
.nojekyll              чтобы GitHub Pages отдавал файлы как есть
```

## Как добавить новый раздел

1. Создайте папку, например `novyj-servis/`, и положите туда `index.html`.
2. Скопируйте в него блок `<nav class="nav">` и относящийся к нему CSS
   из любой существующей страницы — шапка с переходами одинаковая.
3. Добавьте ссылку на новый раздел в этот `nav` на **всех** страницах.
4. На главной (`index.html`) замените карточку «Следующий сервис»
   на карточку нового раздела и при желании добавьте новую пустую.
5. Общие цвета берутся из `:root` в начале каждой страницы,
   шрифт — из `../assets/prata.woff2`.
